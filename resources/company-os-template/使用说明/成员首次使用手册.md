# 成员首次使用手册

## 首次登录（Windows / macOS）

1. 打开 Agent 工作台，安装包会自动创建当前电脑的数据目录。
2. 在登录页输入自己的账号名称，并设置 4–8 位数字 PIN 密码。
3. 再次确认 PIN 密码，点击「创建并进入工作台」。

账号与 PIN 密码仅保存在当前电脑，不需要管理员分配，也不会同步到其他成员设备。若忘记 PIN 密码，可在登录页点击“清除本机账号后重新创建”；公司数据、数据目录和 API Key 均不受影响。

## 日常使用

- 首次创建的本机账号默认可管理当前电脑的工作台；账号与权限不会影响其他成员的设备。
- 所有原始资料上传到对应分身后，会进入 `inbox/`；生成成果在 `outputs/`。请勿直接改动 `knowledge/` 中的资料。
- 工作台左下角「一键同步」用于同步业务资料；不会同步、覆盖或创建其他电脑上的账号。

## 常见问题

- **PIN 密码不对或忘记**：使用登录页“清除本机账号后重新创建”。
- **Windows 环境缺少工具**：点击左下角「本机环境」中的“一键安装”，系统会打开内置安装脚本，自动补齐 Python、PDF 渲染、发票 OCR 和依赖库；完成后重启工作台并重新检测。

## 安全提醒

PIN 仅用于本机工作留痕，不是公司统一密码。不要把客户资料、供应商成本、API Key 或个人信息发到外部平台。
