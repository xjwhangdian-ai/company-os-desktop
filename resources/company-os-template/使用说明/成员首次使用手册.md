# 成员首次使用手册

## 首次登录（Windows / macOS）

1. 打开 Agent 工作台，在登录页点击「先选择公司数据目录」。
2. 选择管理员提供、且已经同步完成的 `company-os` 公司数据目录；不要选择空文件夹或下载目录。
3. 点击「一键同步账号信息」，等待看到账号列表。
4. 点击自己的账号，首次 PIN 为 `123456`。登录后请按提示修改为自己的 4–8 位数字 PIN。

若 PIN 一直不对，请再次点击「一键同步账号信息」。该操作会按管理员花名册恢复员工账号的初始 PIN `123456`，不会覆盖业务资料。仍无法看到账号时，请联系管理员确认：花名册已经随公司数据仓库同步，且你的名字、角色和可见分身已被分配。

## 日常使用

- 左侧仅显示管理员分配给你的数字分身；需要新增权限请联系管理员。
- 所有原始资料上传到对应分身后，会进入 `input/`；生成成果在 `outputs/`。请勿直接改动 `knowledge/` 中的资料。
- 登录页的「一键同步账号信息」和工作台左下角「一键同步」都可用于获取管理员最新的成员与资料更新。

## 常见问题

- **提示未找到账号花名册**：确认选择的是公司数据目录，并让管理员在「设置 → 团队成员与角色」保存成员后执行一次同步。
- **提示 PIN 不对**：先一键同步，再用 `123456` 登录；如仍失败，可使用登录页“清除本机旧账号后重新同步”。
- **Windows 环境缺少工具**：点击左下角「本机环境」中的“一键安装”，系统会打开内置安装脚本，自动补齐 Python、PDF 渲染、发票 OCR 和依赖库；完成后重启工作台并重新检测。

## 安全提醒

PIN 仅用于本机工作留痕，不是公司统一密码。不要把客户资料、供应商成本、API Key 或个人信息发到外部平台。
