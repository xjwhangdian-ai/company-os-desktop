生成台州招投标每日追踪日报（intel 行业情报分身的固定任务）。

目标日期：$ARGUMENTS（未指定则取今天，格式 YYYY-MM-DD）

执行步骤：
1. 若 `input/09_情报_intel/招投标每日/{日期}/` 不存在或为空，先运行数据管线补抓：
   `bash tools/bidding-intel/run_daily.sh {日期}`
2. 读取该目录下的 `{日期}_四平台聚合.md` 与各平台 `*_data_{日期}.json`。
3. 调用 intel 子代理，按其情报简报口径生成日报，写入：
   `outputs/09_情报_intel/招投标每日追踪/{日期}_台州招投标_日报.md`

日报结构（只用 input 数据，零臆造，金额/单位缺失标「待确认」）：
- **TL;DR**：最值得关注的 1-3 条（与公司业务的相关度 + 供哪个分身用）
- **📌 采购意向 / 📢 招标公告 / 🏆 中标结果** 三个分类表：项目名称（带链接）| 采购/招标单位 | 预算或中标金额（万元）| 区县 | 产品大类标签（🚔警用装备/🔧智能化安防/🏗️工程）| 中标单位（如有）
- **🚨 台州公安系统采购**（有数据时单列）：采购单位名称含「公安/交通警察/交警」且含台州区县位置关键词
- **行动建议**：对高相关项目，给 bidding（是否值得跟标）与 sales（是否值得接触客户）各一句可执行建议
- 当日四平台均无新增时，日报只写一行「{日期} 四平台无新增相关信息」+ 数据管线运行状态

4. 日报写完后，在同目录再写 `{日期}_候选项目.json`——只收录**有相关度**的条目（打了 🚔/🔧/🏗️ 标签，或采购单位属公安/应急/政法系统），数组每项：
   `{"id": 序号, "类型": "采购意向|意见征询|采购公告|采购结果公告", "项目名称", "采购单位", "预算_万元", "区县", "标签", "链接", "投标截止"(无则null), "相关度": "高|中", "一句话理由"}`
   （工作台"行业情报"页会把这份相关度标注合并到管线生成的 `{日期}_信息流.json` 全量四类信息流上展示，项目名称必须与信息流原文一致才能对上。）
5. **交互卡片（重要）**：候选项目非空时，在会话里用 visualize 的 show_widget 渲染项目卡片列表（先静默调 read_me 的 interactive 模块）：每张卡片显示 名称/单位/预算/标签/相关度徽章，并带一个「🎯 推送到招投标跟进」按钮，点击执行 `sendPrompt("/跟进项目 {项目名称} {日期}")`；已出现在 `outputs/09_情报_intel/招投标每日追踪/跟进台账.md` 里的项目改为显示「✅ 跟进中」徽章、不出按钮。若 visualize 工具不可用，退化为编号列表并提示用户回复「/跟进项目 <项目名> <日期>」。

注意：
- 乐采云平台依赖本机 Chrome 调试端口(9222)，抓取为空属常见情况，在日报末尾注明数据覆盖情况即可，不要中断。
- 竞争对手中标信息是重要情报，中标表格中我方相关领域的中标单位要保留全名。
- 点击卡片按钮后的 `/跟进项目` 会自动：建 bidding 项目档（input+outputs 分桶骨架）→ 写 _项目卡回填.json 标「跟进中」→ 尝试下载招标文件 → 更新跟进台账 → 调 sales 分身出客户跟进要点。
