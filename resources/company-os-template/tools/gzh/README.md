# 炬视科技 · 公众号一键排版引擎

把任意 Markdown 文稿，一键转成**炬视固定视觉风格**的微信公众号图文（可直接粘贴进公众号编辑器）。
风格走自动化、全公司统一，改样式只改一个文件。

## 一、固定风格（炬视 VI）
- 主色：墨蓝 `#142E4C`　火炬橙 `#F39A0E`　科技青 `#149AAE`　浅青 `#7FD3DC`
- 标题 H2：橙色竖条 + 墨蓝圆角序号牌 + 墨蓝粗体；H3：科技青小方块
- 引用：科技青左边框卡片（适合放"一句话主张"）
- 表格：墨蓝表头 + 斑马纹；列表：橙色方点 / 科技青圆形序号
- 图片：圆角 + 轻投影 + 居中图注；分隔线：橙-青-橙三点（呼应 logo 节点）
- 文末：墨蓝品牌签名卡（炬视 JUSHI TECH · 具身智能 · 视检万物）

## 二、一键用法
```bash
node tools/gzh/gzh_style.js <文稿.md> [输出.html]
# 例：
node tools/gzh/gzh_style.js outputs/2026-06-30_公众号首文_发布版.md
```
1. 浏览器打开生成的 `*_公众号排版.html`
2. 点右上角 **📋 一键复制全文**
3. 到公众号后台编辑器 **粘贴**（Cmd+V）→ 样式即带入

> 自然语言触发：直接对 Claude 说「**把这篇公众号排版**」或「**美化一下这篇推文**」，
> 会自动跑本引擎（等价快捷命令 `/公众号排版`）。

## 三、Markdown 写法约定（让排版自动生效）
| 写法 | 渲染成 |
|------|--------|
| `# 标题` | 居中主标题（橙色下划线） |
| `## 一、xxx` | 带序号牌的章节标题（序号自动递增） |
| `### 小标题` | 青方块小节标题 |
| `> 一句话` | 科技青引用卡片 |
| `**重点**` | 墨蓝加粗 |
| `- 项` / `1. 项` | 橙点 / 青圈列表 |
| `\| 表头 \|` 标准表格 | 墨蓝表头斑马表 |
| `![图注](图片.png)` | 圆角配图 + 居中图注 |
| `---` | 三点品牌分隔线 |

## 四、关于配图（重要）
微信粘贴时 **base64 内嵌图可能被编辑器丢弃**（公众号要求图片上传到自有图床）。
- 预览 HTML 里图片是完整的（base64），用于确认版式。
- 正式发文时，在公众号编辑器对应位置**手动插入** `outputs/` 里对应的 PNG（封面/对比图/架构图等）。
- 封面图（首图）在公众号后台"封面"处单独上传，不放进正文。

## 五、文件
- `gzh_style.js`：转换器（Markdown → 内联样式 HTML，图片转 base64）
- `theme.js`：**样式单一来源**——颜色/标题/表格/卡片/页脚全在这里，改风格只改它
