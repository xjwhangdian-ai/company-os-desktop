# tools/pdf-catalog — 产品画册 PDF 抽图 + 文本提取

把供应商的**数字排版产品画册 PDF**里每个产品照单独抠出来（而不是把每页转成整图），并逐页提取文本层（型号/名称/参数），供 sales 分身/人工整理成带图产品清单。

## 谁用、怎么触发

- **桌面 App**：销售工作台 → 供应商资料上传 PDF → 卡片上点「📖 画册抠图」（主进程调本脚本，仅 Mac 管理员机）。
- **命令行**：
  ```bash
  python3 catalog_extract.py <画册.pdf> <产出目录>
  ```

## 产出（产出目录/ 下）

| 目录/文件 | 内容 |
|---|---|
| `产品图候选/` | 每页检测到的产品照，单独抠出（`P{页}_{序}.jpg`）——核心产物 |
| `文本提取.md` | 每页文本层原文（型号/名称/参数），逐页列出 |
| `_标注/` | 每页标注了候选框**编号**的图，人工/分身照它核对「编号↔产品」 |
| `_整页/` | 每页整页位图，配对复核时看整页 |
| `_候选.json` | 结构化（每页文本 + 候选框坐标/填充率），供按坐标精确裁图 |

## 边界（重要）

- **数字排版画册**（有文本层 + 独立图片对象）效果最好。**整页扫描件**只能抽整页图、文本可能为空——那类改走 App 的「AI 解析入库」（分身读整页图提字）。
- **一页多产品的图文精确配对无法纯机械保证**（版式各异）：候选框会偏多、个别会框到标题/文字。定稿必须由 sales 分身照 `_标注/` **逐页 Read 核对**（配图铁律），或人工挑选。
- 图片最终命名统一 `序号_型号_产品名称_来源页.jpg`。

## 依赖

`pypdf`、`pillow`、`numpy`（缺失时 App 提示 `pip3 install pypdf pillow numpy`）。Windows 成员机暂不支持（无 Python 图像栈），把 PDF 发给销售分身逐页整理。
