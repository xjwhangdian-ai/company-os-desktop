# 输入区（input/，按分身分文件夹）

**统一约定：所有工作流的输入都进这里**，按分身分 10 个子文件夹（与 `outputs/` 的分身文件夹同名镜像），产出则进 `outputs/` 对应分身文件夹按项目归档：

```
input/
  01_销售_sales/  02_解决方案_solution/  03_招投标_bidding/
  04_法务_legal/  05_运营_operation/     06_品牌_brand/
  07_行政人力_ops-policy/  08_财务_finance/  09_情报_intel/
  10_MBA学习_mba/
```

各专属工作流的输入位置（桌面 App 上传自动落位，手动丢文件按同样规则放）：

| 工作流 | 输入放哪 | 说明 |
|---|---|---|
| 招投标 | `03_招投标_bidding/{YYYY-MM-DD_项目名}/` | 每个项目一个文件夹，与 outputs 侧同名配对 |
| 法务 | `04_法务_legal/` | 待审合同平铺，文件名带【销售合同/工程合同/其他】前缀；处理完移入 `已处理/` |
| 销售 | `01_销售_sales/供应商资料/` | 供应商产品资料 / 投标报价文件原件 |
| 解决方案 | `02_解决方案_solution/需求文件/` | 钉钉会议录音（App 本地转写）与需求纪要 |
| 其余分身 | 各自子文件夹根 | 聊天里上传的普通参考文件 |

处理完成的普通参考文件建议手动移出或删除，保持各自 input 文件夹整洁。
