# 评分优化案例库

放置：评分办法中各答题点（尤其是主观评审类、没有标准答案的得分点，如技术方案优劣、服务承诺可信度、项目理解深度等）的高分写法参考——可以是脱敏后的历史中标标书片段、评标反馈、或人工整理的"好答案范例"。

> 这是一个持续导入数据的库，目前处于起步阶段，后续会陆续补充案例。每次使用前看一遍是否有新内容。

## bidding 分身怎么用
起草评分点应答内容（尤其主观分部分）前，先来这里找同类评分点有没有可参考的写法范例：
- **只借鉴写法结构、论证颗粒度、覆盖维度的方式**，不得整段照抄别的项目的具体参数、案例、客户名安到本项目上。
- 库里没有可参考案例时，仍必须针对该评分点结合 `knowledge/products/` 的真实产品能力写出实质性应答，不能因为没案例就用空话套话应付或跳过。
