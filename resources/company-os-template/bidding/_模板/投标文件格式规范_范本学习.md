# 投标文件格式规范（学习自中标范本，bidding 分身编标必读）

> 来源：`inbox/03_招投标_bidding/招投标文件模板/招投标文件模板-AI/` 下两对真实招标↔投标文件
> （椒江区智慧停车场设备采购、2022年智安小区视频监控采购，投标方均为头部厂商），逐段解析其版式与结构后提炼。
> 适用：所有项目的投标文件初稿（.md）编写。App 转 Word 时的字体/字号已按本规范内置（宋体系），
> **分身负责把"结构"写对，转换器负责把"样式"排对**。

---

## 一、总原则（三条铁律）

1. **结构服从招标文件**：每个项目先读招标文件"投标文件的组成"与"投标文件格式"章节，**目录顺序、册划分、附件编号严格照抄招标文件**，本规范只补招标文件没规定的部分。
2. **凡有给定格式的附件全文照搬式样**（声明书/承诺函/偏差表等），只把待填处留空标〔待填〕，绝不自创措辞或改表头。
3. **按评标办法组织正文章节**：技术/商务论述部分的章节树 = 评标办法评分表的评分项，每个评分点独立成节，让评委按分找页。

## 二、文件骨架（范本共性结构）

```
封面
目录
┌ 大节1（如 技术规格偏差表）
│   ├ 节头两行：第1行 项目名称（居中）／第2行 节名（居中）
│   ├ 正文/表格
│   └ 签章尾三行
├ 大节2（如 类似项目业绩一览表）……
└ 大节N（投标人根据评标办法编制商务技术文件）
    ├ 二级：投标人荣誉 / 投标人情况说明 / 项目组成员 / 技术方案 / 售后服务……（照评分项）
    ├ 三级/四级/五级逐层展开论述
    └ 图片配图注（居中一行小字）
```

### 1. 封面（md 里用代码块表达，一项一行）

```
项目名称（居中大字）
项目编号：XXX

投
标
文
件
（□□□□文件）        ← 册名，照招标文件：商务技术文件/资格及商务技术文件/报价文件

供应商全称（公章）：
地址：
时　　间：
```

要点：投/标/文/件 四字竖排（每字一行、居中特大号）；册名括注；底部三行落款左对齐。

### 2. 目录

- 单独一页，标题「□□□□文件目录」居中；
- 目录条目 = 大节名清单，顺序与正文严格一致（Word 里由人工/转换器生成页码）。

### 3. 大节节头（范本每个大节都这样开头）

```
（另起一页）
项目名称                    ← 居中
节名（如 技术规格偏差表）    ← 居中
```

md 写法：每个大节用 `# 一级标题` 开（转 Word 自动分页），标题下先写两行居中引导（项目名+节名）。

### 4. 签章尾（每个独立表格/声明的末尾三行，一字不差）

```
投标人名称（盖章）：
法定代表人或授权代表（签字或盖章）：
日　　期：
```

### 5. 表格规范

- **偏差表**（技术/商务响应核心表）：列头 `章节号 | 招标文件技术要求 | 投标人的偏差 | 投标人偏差的理由 | 备注`（或照招标文件给定列）；
  - 「章节号」精确到招标文件的章-节-条（如"第五章招标需求-第一节项目清单及参数-3、道闸"）；
  - 「招标文件技术要求」**逐条原文照抄**，一条不落（含▲★条款，▲★符号保留）；
  - 偏差结论用语固定：**正偏离，优于招标文件技术要求 / 无偏差 / 负偏离（附具体说明）**；
  - 表尾注固定："注：如本页未填写或未提供，均视为完全满足采购文件要求，无偏差。"
- **业绩表**：列头 `业绩名称 | 委托方名称 | 委托日期 | 证明材料名称 | 备注`，表后注明"后附证明材料复印件"。
- 所有表格单元格内容居中（长文本除外），表后接签章尾。

### 6. 标题层级与正文（评分响应部分）

- 最多用到 5 级标题（章-节-小节-条-目），逐层递进，**每级标题都要有实质内容支撑**，不写空标题；
- 正文成段论述，每段聚焦一个点；方案类内容按"背景/问题 → 方案 → 机制/流程 → 效果"展开；
- 图片：图下一行居中小字图注（如"普通出入口相机　海康出入口抓拍机"）；
- 涉及具体数字（响应时间、参数、人数、业绩额）必须有来源，没有依据的写〔待确认〕。

## 三、字体字号（App 转换器已内置，分身无需手动排）

| 元素 | 范本口径 |
|---|---|
| 正文 | 宋体（西文 Times New Roman）小四 12pt |
| 一级标题 | 宋体加粗 18pt |
| 二级标题 | 宋体加粗 16pt |
| 三级标题 | 宋体加粗 14pt |
| 封面项目名 | 26pt 居中；投标文件四字 42pt；落款 16pt |
| 图注 | 11pt 居中 |

## 四、内容红线（与格式同权重）

1. 《资格及商务技术文件》内**严禁出现投标报价**（分册隔离）；
2. ▲★号实质性条款必须逐条正面响应，漏一条=废标风险；
3. 品牌/型号口径全册一致，与检测报告一致（涉标品类双轨制）；
4. 招标文件要求签章/盖章的位置在 md 里保留提示行，不省略；
5. 成本测算、供应商采购价等内部信息严禁写入。
