# 历史中标信息 · 人工补查清单（zfcg 浙江政府采购网）

> 用途：4 份招标解析中，部分项目的历史中标单位/品牌/价格因政府站点验证码/登录/站内检索限制未能联网取到。本清单给出可照着操作的检索路径、关键词、筛选条件与采集模板，由人工登录补齐后回填各解析报告的「历史中标对比」节。
> 原则：只采信公告原文，记录来源链接；近义品类不可混为比价。

---

## 一、检索平台与路径

| 平台 | 网址 | 检索路径 |
|------|------|----------|
| 浙江政府采购网（主） | https://zfcg.czt.zj.gov.cn/ | 首页 →「结果公告 / 中标（成交）公告」检索框 → 设关键词+区域+时间+公告类型 |
| 中国政府采购网（全国） | http://www.ccgp.gov.cn/ | 首页搜索 →「中标公告/成交公告」频道，按地区/时间筛选 |
| 浙江政采云 | https://www.zcygov.cn/ | 项目采购公告检索（部分需登录） |
| 第三方聚合（可选，部分付费） | 千里马招标网 / 比地招标网 / 中国采购与招标网 | 关键词搜索，交叉验证，仍以政府站原文为准 |

**通用筛选建议**：行政区域先「台州市」→ 取不到再放宽「浙江省」；时间范围近 24–36 个月；公告类型选「中标公告 / 成交公告 / 结果公告」；如有「采购品目」筛选，选对应货物大类。

## 二、分项目关键词与排除词

### ① 特检院检验设备（标项一 便携式 LIBS / 标项二 射线底片数字化）
- 标项一主关键词：`便携式LIBS` / `激光诱导击穿光谱` / `手持式光谱仪` / `合金分析仪` / `便携式光谱仪`
- 标项二主关键词：`射线底片数字化` / `底片数字化扫描仪` / `射线底片扫描` / `底片数字化分析仪` / `AI评片` / `智能评片`
- 采购人线索：`特种设备检验` / `特检院` / `检验检测研究院`
- ⚠️ 排除/区分：LIBS ≠ 手持 `XRF`（X 荧光），勿混；底片数字化 ≠ 普通文档扫描仪
- 重点核：标项一是否要求测 **碳(C)** 并给精度；标项二扫描仪是否要求 **CNAS / BAM** 证书（缩小厂家范围的关键门槛）

### ③ 防暴救援装备
- 主关键词：`防暴装备` / `防暴器材` / `单警装备` / `警用防暴` / `救援装备` / `防暴救援`
- 高价值单项：`巡逻摩托艇` / `救生艇`（占总额约 69%，单独查中标价最有参考性）；`强光炫目器` / `强光手电`
- 警械单项（合规重点）：`OC喷射器` / `催泪喷射器` / `胡椒喷雾`（受公安管控，查谁能合规供货）
- 采购人线索：`公安局` / `特警支队` / `应急管理`
- ⚠️ 排除：纯消防器材、纯劳保用品

### ④ 可见-短波红外相机（恩泽医疗，最优先项目）
- 主关键词：`短波红外相机` / `SWIR相机` / `InGaAs相机` / `可见短波红外` / `可见-短波红外`
- 传感器/型号线索：`IMX992`（Sony 传感器，命中即高度相关）
- 采购人线索：`医院` / `医疗中心` / `高校` / `研究所` / `实验室`
- ⚠️ 排除（极重要）：`红外热像仪` / `测温` / `长波红外` / `LWIR` / `热成像` —— 均非同类，价格不可比

### ②（已取到 2 条，可扩展核验）无人机装调检修实训室
- 主关键词：`无人机实训室` / `无人机装调检修` / `无人机组装调试` / `无人机维修实训` / `无人机教学设备`
- 已取到参考：湖州职院 ≈169.65 万、遂宁职校 ≈88.71 万（见解析报告，需回原公告复核链接）
- ⚠️ 排除：纯无人机整机采购（非实训室/教学）

## 三、采集模板（每条中标记录填一行，回填到对应解析报告）

| 字段 | 填写说明 |
|------|----------|
| 项目名称 | 公告原文标题 |
| 项目编号 | 公告原文 |
| 采购人 / 地区 | 单位 + 行政区域 |
| 公告日期 | 中标/成交公告发布日 |
| 中标供应商 | 公告原文全称 |
| 品牌 / 型号 | 如公告或清单披露；未披露写「未披露」 |
| 中标金额 / 单价 | 总价；能拆到单台/单项更好 |
| 数量 | 对应单价口径 |
| 来源链接 | 公告 URL（务必留存） |
| 置信度 | 【公告原文】/【聚合站转载待核】 |

> 比价提醒：优先取「同采购人地区 + 同品类 + 近2年 + 可拆单价」的样本；进口与国产、制冷与非制冷、是否含集成/售后，口径不同不可直接比，需在备注里标注差异。
