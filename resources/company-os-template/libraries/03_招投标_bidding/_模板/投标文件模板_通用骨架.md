# 第一页 · 废标项自检表（每份投标文件必备首页）

> **编标第一步**：通读招标文件，把全部废标/无效投标条款提取到此表。**按招标文件部次逐处扫**（不同代理机构叫法不同，两类常见体系都要覆盖）：
> ① 第二部分「前附表 / 投标资料表」——最高限价、投标有效期、备份投标文件规则、递交方式等硬性条款；
> ② 第三部分「招标文件 / 投标人须知」——「无效投标认定」专条（常按 资格审查 / 符合性审查-技术商务 / 符合性审查-报价 三组列出）+ 澄清修正、串通投标情形；
> ③ 第四部分「投标文件」（格式和内容要求）——组成、编制、签章（CA）、语言计量、报价规则里的"作无效投标处理"条款；
> ④ 采购内容/需求章节里的 ▲/★ 实质性条款与专项承诺要求（如无线电设备型号核准证承诺，未提供作无效标）；⑤ 资格条件红线（含信用中国/中国政府采购网失信名单否决）。
> 逐条原文口径入表，编标中随时对照、交稿前逐项打勾。〔正式递交版是否保留此页按内部流程定〕

| # | 废标条款（招标文件原文口径） | 出处（章节/页码） | 我方核对状态 |
|---|---|---|---|
| 1 | 〔逐条填入，不得归并省略〕 | 〔如：投标人须知五(五)-1〕 | 〔待核/✓已核〕 |

⚠️ 另附「非废标但有后果」事项（如开标后限时提交材料、评分项关联定位要求等）。

# 附：结构B——「投标资料表」体系的三册组成（中冠等代理机构常用，台州公安项目多见）

> 招标文件呈「采购公告/投标资料表/投标人须知/评标办法/采购内容/合同文本/格式与表格」七部分结构时，投标文件按其第四部分「投标文件」的组成编制，通常为**三册**，各册打头文件固定：

**① 资格证明文件**：资格条件自查表（首页，格式见附件）→ 营业执照扫描件 → 关于资格的承诺函 → 授权委托书/法定代表人身份证明 → 中小企业声明函（或监狱企业/残疾人福利单位证明）→ 其他资格材料。〔证书/合同/报告等证明材料用**原件清晰扫描**做入投标文件〕

**② 商务技术文件**：商务技术自评表（首页）→ 供应商基本情况表 → 证书一览表 → 供货清单 → 技术条款偏离表 → 商务条款偏离表 → 相关项目实施业绩一览表 → 服务响应承诺函 → 评分标准要求的其他材料 → 其他商务技术资料。

**③ 报价文件**：投标函（首页）→ 开标一览表 → 报价明细表 → 本国产品标准声明函（如适用）→ 其他报价资料。

报价规则红线：只报一个价（两个以上报价未声明取向即拒绝）；单价中标后固定不变，**任何含价格调整要求的投标作无效投标处理**；报价涂改处必须盖章/签字确认否则无效。
