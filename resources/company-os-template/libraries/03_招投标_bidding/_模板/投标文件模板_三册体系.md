# 投标文件模板 · 三册体系（投标资料表体系）

> 适用：招标文件呈「第一部分采购公告 / 第二部分投标资料表（前附表）/ 第三部分投标人须知 / 第四部分评标办法 / 第五部分采购内容及要求 / 第六部分合同文本 / 第七部分格式与表格」七部分结构时（中冠等代理机构常用，台州公安项目多见）。
> 提炼自《台州市公安局无人机侦测反制设备及反制车改装项目》招标文件第七部分格式与表格 +《投标文件的格式和内容要求》。
> 使用规则：**每个项目以招标文件第七部分给定的格式附件为准**，与本模板不一致处照招标文件改；〔〕为待填占位。
> 两册体系（资格及商务技术文件+报价文件）见《投标文件模板_通用骨架.md》。
