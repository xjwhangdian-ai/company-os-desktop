# 炬视数字人分身工作台 · Windows 安装与使用说明

> 适用：在 Windows 电脑上安装、配置、使用本工作台的同事。
> 功能怎么用见另一份《使用手册》，本篇只讲 **Windows 上的安装、首次配置，以及当前的平台差异**。

---

## 一、拿到安装包

安装包是一个 `.exe` 文件，名字形如：

```
炬视数字人分身工作台 Setup 0.1.0.exe
```

**怎么拿到它（管理员，任选其一）**：

- **方式 A（推荐，云端自动打包）**：仓库已配好 GitHub Actions。打开仓库
  `xjwhangdian-ai/company-os-desktop` → **Actions** 标签 → 左侧「Build Windows Installer」
  → 「Run workflow」。几分钟后在这次运行页面底部 **Artifacts** 里下载 `windows-installer`
  （解压得到 `.exe`）。
  - 也可以打版本标签自动出包并发到 Release：本地 `git tag v0.1.0 && git push origin v0.1.0`，
    构建完成后到仓库 **Releases** 页下载。
- **方式 B（本地 Windows 电脑打包）**：见同目录 `打包Windows说明.md`。

**普通员工**只需拿到管理员给的这个 `.exe` 即可，**运行它不需要另装 Node/Electron**，运行环境已内置在安装包里。

---

## 二、安装步骤

1. 双击 `炬视数字人分身工作台 Setup x.x.x.exe`。
2. **会弹出蓝色提示「Windows 已保护你的电脑 / 未知发布者」**——这是因为安装包**未做代码签名**，属正常现象。
   点提示里的 **「更多信息」→「仍要运行」** 即可继续。
   - 如果双击没反应或被杀毒拦截：右键该 `.exe`→「属性」→ 勾选「解除锁定」→ 确定，再运行。
3. 选择安装位置（可用默认），点「安装」。
4. 安装完成，**桌面和开始菜单**会出现「炬视数字人分身工作台」图标。
5. 以后卸载：Windows「设置 → 应用」里找到它卸载即可。

---

## 三、第一次打开（配好三样就能用）

1. **选公司 → 选自己的名字**（可设 4 位 PIN；忘了找管理员重置）。
   - 这只是给产出文件留「谁做的」痕迹，不是账号安全系统。
2. **数据目录**（管理员配一次）：指向本机的 `company-os` 仓库文件夹，例如
   `C:\Users\你的用户名\company-os`。里面应有 `knowledge\`、`outputs\`、`bidding\` 等子目录。
   - 本机还没有这个文件夹？见下面第四节。
3. **模型供应商 + API Key**（管理员配一次）：选供应商、填 Key（只存本机，不上传）。

配好后，**普通员工直接用分身干活即可，看不到设置页**。

## 四、数据目录从哪来（Windows 成员机）

App 需要一个「数据目录」——也就是公司的 `company-os` 仓库。管理员的 Mac 上已经有；Windows 成员机通常这样准备：

1. **装一次 Git**：到 https://git-scm.com/download/win 下载安装（一路默认即可）。
2. **拿仓库地址**：成员电脑一般连不上 GitHub，所以远程通常指向
   **管理员机的内网共享仓库**或 **Gitee**（地址找管理员要，拓扑见同目录 `SETUP.md`）。
3. **克隆到本地**：打开「命令提示符」或「Git Bash」，执行：
   ```
   git clone <管理员给你的地址> C:\Users\你的用户名\company-os
   ```
4. 回到 App 设置页，把**数据目录**指到 `C:\Users\你的用户名\company-os`。
5. 之后用左下角 **☁️ 一键同步** 拉取最新 / 提交改动（同步依赖 Git，已装好即可）。

## 五、Windows 与 Mac 的功能差异（重要，务必先看）

程序已做跨平台适配，Windows 11 上正常运行。少数依赖外部工具或特定环境的功能，情况如下：

| 功能 | Windows 现状 | 说明 |
|---|---|---|
| 运营 · 公众号一键排版 | ✅ 可用 | 已改用软件内置运行时，**无需另装 Node.js** |
| ☁️ 一键同步 | ✅ 可用（需装 Git） | 装一次 Git（https://git-scm.com/download/win），远程指内网仓库/Gitee |
| 解决方案 · 录音转写（whisper） | ✅ 装了引擎就能用 | 需 `pip install openai-whisper` + 安装 ffmpeg 并加入 PATH；未装则提示安装 |
| 招投标 · 「下载招标文件」自动抓取 | ⚠️ 按设计走手动 | 依赖政采登录抓取栈（Mac 管理员机就绪）；Windows 点公告链接手动下载后拖进 `01_招标文件/` |
| 行业情报 · 每日自动抓取 | ⚠️ 任务在 Mac 管理员机 | 情报数据靠同步过来；Windows 本机不自动抓取 |

**以下功能 Windows 全部正常可用**：

- 9 个分身对话、各工作台上传资料与生成产出、右侧「转 Word」导出；
- 销售：产品库 / 报价单 / 客户 CRM，Excel 供应商资料导入；
- 招投标：项目台账、项目卡、招标解析 / 写质疑函 / 生成投标文件 / **导出三册 Word**；
- 法务：合同上传、审核意见书、与模板对比；
- 运营 / 品牌 / 行政人力 / 财务：对话式生成与产出，公众号一键排版；
- 行业情报：查看已同步的招投标信息 / 研报（只读、确认跟进）。

> 招标文件自动下载在 Windows 上按设计走手动（成员机通常没有政采抓取环境）。若确有需要在某台 Windows 上启用自动下载，联系管理员单独配置。

## 六、常见问题

| 现象 | 怎么办 |
|---|---|
| 双击装不了 / 被拦 | SmartScreen：「更多信息 → 仍要运行」；或右键 .exe →属性→「解除锁定」；杀毒软件加信任。 |
| 打开后一直停在「请先完成设置」 | 数据目录或 API Key 没配好，让管理员进设置页补齐。 |
| ☁️ 同步失败 | 确认已装 Git；远程要指向内网仓库/Gitee（找管理员），不是 GitHub。 |
| 看不到「⚙️ 设置」 | 只有管理员可见；要改配置请联系管理员。 |
| 录音转写点了提示装引擎 | 按提示 `pip install openai-whisper` 并装 ffmpeg 加入 PATH；装好重开软件即可。 |
| 下载招标文件走手动 | Windows 上按设计走手动：点公告链接下载后拖进项目 `01_招标文件/`。 |
