# 炬视数字人分身工作台 · 团队使用手册

> 适用对象：公司全体使用本工作台的同事
> 一句话：把公司统一资料 + AI，装进一个桌面软件。9 个「数字人分身」对应公司 9 类角色，你只管上传资料、说需求、拿产出，不用记命令、不用手动整理文件夹。

---

## 一、这个软件是什么

- 左边一列是 **9 个分身**（销售 / 解决方案 / 招投标 / 法务 / 运营 / 品牌 / 行政人力 / 财务 / 行业情报）。点谁就进谁的工作台。
- 每个工作台大体是三块：
  - **左侧工具区**：上传资料、管项目、看库；
  - **中间对话区**：跟这个分身说需求、让它干活；
  - **右侧产出面板**（点 `‹` / `›` 展开）：列出这个分身生成的文件，可「转 Word」、可在 Finder 里定位。
- 所有资料和产出都放在一个**数据目录**（company-os 仓库）里，分门别类，不会乱。

---

## 二、第一次使用（开机到能干活）

1. **首次安装直接创建自己的账号和 PIN 密码**（4–8 位数字），随后用该账号登录。账号只保存在当前电脑，不需要管理员分配；忘记 PIN 时可在登录页清除本机账号后重新创建。
2. **管理员 vs 普通员工**
   - 管理员：能进 **⚙️ 设置**（配数据目录、模型供应商、分配账号），**可见全部 9 个分身**。
   - 本机普通账号：看不到设置页；只看到当前电脑上为其配置的分身（不勾=全部可见）。
3. **⚙️ 设置页（管理员配一次）**
   - **数据目录**：指向 company-os 仓库根目录（里面有 knowledge/、outputs/、bidding/ 等）。**没有现成目录？** 点公司行的「初始化目录」按钮，从安装包内置模板一键创建全新数据目录（含 9 个分身定义、知识库、全部文件夹骨架）。
   - **模型供应商**：点一个标签切换，对全部 9 个分身生效；每个供应商的 Key 独立保存。支持 Anthropic / DeepSeek / MiniMax / 通义千问 / **智谱 GLM** / 自定义。
   - **API Key**：只存本机，不会同步到仓库或网络。
4. **数据同步策略（v0.1.1 起）**
   - **数据不走 git**：git 只用于应用程序本身的更新（装新版安装包即可），资料与产出留在各自电脑本机。
   - **行业情报自动拉取**：打开「行业情报」分身时，App 自己从三大平台抓取最近三天的招投标信息，任何电脑都能用，无需同步。
   - 左下角 ☁️ 同步按钮只在管理员的开发机上出现（数据目录是 git 仓库时）；成员机器看不到它，属正常。

## 三、每个分身都通用的几个操作

| 元素 | 作用 |
|---|---|
| **📎 上传** | 文件复制进 `inbox/` 下**当前分身自己的文件夹**（如销售 → `inbox/01_销售_sales/`），发消息时一并带给分身读取。 |
| **输入框** | `Enter` 发送，`Shift+Enter` 换行。 |
| **停止** | 任务进行中出现，点它中断本次调用（**已生成的文件不会撤销**）。 |
| **⚡ 快捷指令** | 部分分身有预设模板按钮，点了会**填进输入框**，你改好占位内容再发，不会自动发出去。 |
| **‹ / › 产出面板** | 右侧展开，列出 `outputs/该分身/` 的产出，可「转 Word」、可定位到 Finder、可另存副本。 |

## 四、9 个分身逐个说明

### 1. 销售（sales）—— 产品库 / 报价单 / 客户 CRM
- **什么时候用**：对客户报价、整理产品库、维护客户跟进。
- **首次使用**：安装包不包含产品清单，先点击「同步数据」下载已发布的销售目录；不需要配置 Git 或登录 GitHub。
- **发布更新**：维护产品库的管理员在核对完成后点击「发布产品库」。首次发布前在「设置 → 产品库发布」配置仅有 `company-os-desktop` 仓库 `Contents: Read and write` 权限的 GitHub Fine-grained Token。发布采用字段白名单：仅含产品、分类、参数和销售报价；成本、供应商、联系人、原始资料及图片路径不会发布。
- **上传入口**：
  - `📎 供应商资料`：xlsx/csv/pdf/docx/doc。Excel 表头能对上（品名/单价/厂家）可「直接导入」（不耗 AI）；对不上的和 PDF/Word 点「AI 解析入库」。→ 落 `inbox/01_销售_sales/供应商资料/`
  - `🏷️ 投标报价文件`：上传投标报价表，按产品名回填投标报价到产品库。
- **产出目录**：报价文件 → `outputs/01_销售_sales/{日期_客户_报价}/`
- **要点**：价格分三档——**成本价（采购侧）/ 建议销售价（对客户）/ 投标报价**。**成本价、供应商联系方式绝不进对外报价单。**

### 2. 解决方案（solution）—— 需求文件 / 资料库 / 生成方案
- **什么时候用**：把钉钉会议需求变成一份技术/解决方案。
- **上传入口**：`需求文件` 上传录音（mp3/m4a/wav）和需求纪要（md/docx/pdf）→ 落 `inbox/02_解决方案_solution/需求文件/`
- **特色**：录音在**本机离线 whisper 转写**（不耗 AI 额度、不上传外网），生成 `xx_转写.md`。首次用需装一次引擎（工作台会给命令），重要数字建议对照录音核对。
- **产出目录**：方案 → `outputs/02_解决方案_solution/{日期_项目}/`（右侧「转 Word」）
- **要点**：产品名称/参数以 `knowledge/products/` 为准。

### 3. 招投标（bidding）—— 台账 / 项目卡 / 三册投标文件
- **什么时候用**：处理招标文件、写质疑函、拼投标文件。
- **上传入口**：
  - `＋ 新招标项目`：选招标原件 → 自动建项目并触发解析。→ 落 `inbox/03_招投标_bidding/{日期_项目}/01_招标文件/`
  - `＋ 答疑澄清`：答疑/澄清/变更公告 → 项目的 `02_答疑澄清/`
  - `📎 上传素材`：补传资料到**跨项目共享素材库**（不是本项目专属）。
- **台账与分类**：项目列表**按公告类型分组**（📌采购意向 / 📋意见征询 / 📢采购公告 / 📁其他），可折叠；按投标截止日倒计时排序（3 天内红色），可按状态筛选；「导出 CSV」出整表台账。
- **下载招标文件**（项目详情内）：
  - 采购意向 → 直接提示「无正式招标文件」；
  - 意见征询 / 采购公告 → 先探测附件清单，**弹窗让你确认后再下载**到 `01_招标文件/`。
  - 非浙江政采源 / 需登录时按提示手动下载或先登录调试浏览器。
- **忽略项目**：项目详情右上「忽略」→ 把该项目两侧文件夹**移入系统废纸篓（可恢复）**。
- **产出目录**：`outputs/03_招投标_bidding/{同名项目}/`（`01_招标解析`/`02_报价文件(内部)`/`03_技术方案`/`04_投标文件成稿`/`05_合同与履约`）。投标初稿生成后可「导出三册 Word」。
- **要点**：`02_报价文件/` 是**内部成本测算，内容严禁进对外投标文件**。

### 4. 法务（legal）—— 待审合同 / 审核意见书 / 模板对比
- **什么时候用**：审销售/工程/其他合同、法律材料把关。
- **上传入口**：上传待审合同时选类型（销售/工程/其他）→ 落 `inbox/04_法务_legal/`
- **动作**：「审核」出《合同审核意见书》；「与模板对比」逐条比差异；「标记已审」把原件移入 `已处理/`（纯移动，不经过 AI）。
- **产出目录**：`outputs/04_法务_legal/{日期_合同名}/`

### 5. 运营（operation）—— 新媒体内容 / 公众号排版
- **什么时候用**：写小红书 / 公众号图文、短视频脚本。
- **上传入口**：`🖼️图片` / `🎬视频` / `📄其他文件` 三个按钮按类型选文件 → 落 `inbox/05_运营_operation/`
- **动作**：选平台（小红书 / 微信公众号）决定内容骨架；`✍️生成内容`；公众号可用 `🎨一键排版`（纯脚本转炬视风格 HTML，不耗 AI，点「一键复制」粘进公众号编辑器）。
- **产出目录**：`outputs/05_运营_operation/`

### 6. 品牌（brand）—— 对话式工作台
- **什么时候用**：Logo 方向、VI、企业文化、官网栏目与文案。上传参考 → `inbox/06_品牌_brand/`，产出 → `outputs/06_品牌_brand/`。

### 7. 行政人力（ops-policy）—— 对话式工作台
- **什么时候用**：规章制度、SOP、行政模板、招聘人事、内部制度。上传 → `inbox/07_行政人力_ops-policy/`，产出 → `outputs/07_行政人力_ops-policy/`。

### 8. 财务（finance）—— 对话式工作台
- **什么时候用**：财税、发票、成本、报销、预算、财务测算。上传 → `inbox/08_财务_finance/`，产出 → `outputs/08_财务_finance/`。

### 9. 行业情报（intel）—— 招投标信息 / 行业趋势 / 政策文件
- **什么时候用**：看每日招投标线索、行业研报、政策文件，并一键推给招投标分身跟进。
- **三个标签**：
  - **招投标信息**：打开页面时 **App 自动从三大平台抓取**最近三天公告（浙江政采/台州公共资源/台州阳光采购，任何电脑都能抓，无需同步）；按 采购意向/意见征询/采购公告/采购结果公告 分组；点「✓ 确认跟进」自动建招投标项目档（在招投标分身里带 🆕 待处理 标记），「忽略」不再出现。「刷新」按钮可随时强制重抓。
  - **行业趋势 / 政策文件**：来自研报（sgpjbg.com，需会员登录），由管理员机每日抓取，只读，点标题跳下载页。
- **自动清理**：打开情报分身会**自动清除超过三天的旧机读数据**（信息流/候选/研报 JSON），**日报、台账等人读产出保留**。
- **产出目录**：`outputs/09_情报_intel/`（每日追踪、研报追踪、日报等）。

## 七、跨项目「库」在哪（既不是输入也不是产出）

这些是可反复复用的资料库，**留在各自工作区目录**，不放进项目：

- 招投标素材库：`bidding/_素材库/`（产品资料/检测报告/解决方案/人员资质/类似合同）、模板 `bidding/_模板/`
- 销售产品库：`销售/产品库/产品库.json`、客户库 `销售/客户库.json`、报价模板 `销售/_模板/报价模板/`
- 方案取材库：`解决方案/基础产品库/`、`解决方案/基础解决方案库/`、`解决方案/_模板/`
- 法务模板：`法务/_模板/`
- 公司只读资料：`knowledge/`（公司事实/产品/品牌/招投标历史，**只读，任何人任何分身都不要改**）

## 八、几条红线（全员必读）

1. **`knowledge/` 只读**——公司统一口径来源，不改不删。
2. **对外产出禁含内部敏感信息**：个人联系方式、成本价、供应商联系人、融资/估值/财务预测。
   - 销售报价、投标文件里**成本价与采购侧信息绝不出现**。
3. **找不到来源的数字写「待确认」**，不编造资质/参数/检出率。
4. **账号密码绝不写进任何文件/配置**（如政采网站登录，只在浏览器里手动登录）。

## 九、常见问题 FAQ

| 现象 | 原因 / 怎么办 |
|---|---|
| Mac 安装时提示"已损坏，无法打开" | 不是真损坏——微信/浏览器传来的安装包带隔离标记，而 App 未做苹果签名公证。终端执行 `xattr -cr /Applications/炬视数字人分身工作台.app` 后正常打开即可（每台新 Mac 首次装需做一次；U 盘拷贝的不会遇到）。 |
| 录音转写没反应 | 本机还没装 whisper 引擎，按解决方案工作台给的命令装一次。 |
| 点「下载招标文件」没动静 | 采购意向本就无文件；或需先在弹出的调试 Chrome 登录政采；或非政采源需点公告链接手动下载。 |
| 情报数据「变少了」 | 正常——情报分身自动只留最近三天机读数据，日报/台账仍在。 |
| 行业情报是空的 | 打开「行业情报」页等它自动抓取（首次约十几秒），或点「刷新」强制抓；仍空则是网络问题。行业趋势/政策文件两个标签的数据来自管理员机，成员机为空属正常。 |
| 找不到 ☁️ 同步按钮 | v0.1.1 起数据不走 git 同步，该按钮只在管理员开发机上出现；成员机没有它属正常，不影响任何功能。 |
| Excel 导入缺行/报错 | 表头对不上会漏（可点 AI 解析入库）；`.xls` 旧格式请另存为 `.xlsx`。 |
| 找不到「设置」按钮 | 只有管理员可见；需要改配置请联系管理员。 |
| 忘记 PIN | 在登录页清除本机账号后重新创建；不会删除公司数据、数据目录或 API Key。 |
| 左侧只有几个分身 | 本机普通账号只显示当前电脑配置的分身；由该电脑的管理员在“本机账号与角色”中调整。 |
